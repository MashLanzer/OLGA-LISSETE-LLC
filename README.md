# Olga Lissete LLC — The Clean Touch Janitorial Services

Pilot / demo website for **Olga Lissete LLC**, a professional janitorial &
commercial cleaning company serving banks, offices, dental & medical
facilities, retail and commercial buildings across Florida.

> ⚠️ **This is a pilot demo, not the live site.** Pricing shown in the
> instant estimate is illustrative only, and the contact form opens the
> visitor's email app with the request pre-filled.

## What's inside

A single, self-contained `index.html` — no build step, no dependencies.
Just open it or serve it statically (e.g. GitHub Pages).

Highlights:

- **Modern, responsive design** with light/dark mode and brand-blue identity
- **Instant estimate calculator** — live monthly ballpark by facility type,
  square footage, frequency and add-ons
- **Interactive scope-of-work sheet** — task/frequency matrix per facility type
- **Scroll-driven reveals, animated counters and a sticky scroll progress bar**
- **Accessibility**: semantic HTML, focus styles, `prefers-reduced-motion`
  support, ARIA on interactive widgets
- **SEO**: meta/Open Graph tags and JSON-LD `ProfessionalService` structured data
